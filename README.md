 🎯 Зачем нужен этот проект?
В современном бизнесе понимание своей аудитории — это ключ к успеху. Этот проект решает задачу **автоматической сегментации клиентов** без участия человека. 

Вместо того чтобы вручную анализировать тысячи строк данных, алгоритм машинного обучения сам находит скрытые закономерности и делит базу на группы. Это позволяет:
Персонализировать маркетинг: предлагать скидки только тем, кому они нужны.
Удерживать клиентов: вовремя замечать "транжир" с низким доходом или лояльных VIP-клиентов.
Оптимизировать бюджет: не тратить деньги на рекламу по тем, кто всё равно не купит.

🛠 Как это работает (Под капотом)
Проект построен на стыке **Data Science** и **Web Development**:
1. Препроцессинг:** Мы берем данные о годовом доходе и рейтинге трат. С помощью `StandardScaler` мы приводим их к единому масштабу, чтобы алгоритм работал корректно.
2. Кластеризация (K-Means):** Алгоритм ищет центроиды (центры масс) в облаке данных и притягивает к ним похожих клиентов. Мы выделили **5 ключевых сегментов**.
3. Веб-интерфейс:** Flask-сервер принимает данные через форму, прогоняет их через обученную модель и мгновенно выдает результат с визуализацией на графике.

## 👤 Кому это подойдет?
Владельцам интернет-магазинов:** для настройки e-mail рассылок.
Маркетологам:** для анализа эффективности текущей стратегии.
Data-аналитикам:** как база для более сложных систем рекомендаций.
Студентам и разработчикам:** как пример интеграции ML-модели в реальное веб-приложение.

## 📁 Структура репозитория
* `app.py` — серверная часть на Flask, логика предсказания и генерации графиков.
* `train.py` — "тренировочный лагерь": здесь обучается модель и сохраняется в `.pkl`.
* `templates/` — фронтенд часть (HTML-интерфейс).
* `data/` — датасет `Customer_Data.csv` (на основе которого учится модель).
* `model/` — мозг системы: сохраненный скейлер и сама модель K-Means.
